# Language.fi — Language is Liquidity

A linguistic asset protocol where letters become priced primitives, words become composable value objects, and sentences become transferable registered assets through a public registry and dynamic alphabet oracle.

## Overview

Language.fi creates a market layer for language itself. Letters become dynamically priced primitives. Words and names inherit value from their characters. Sentences can be minted as unique registered assets with ownership, cost basis, and transfer history.

**Important:** This is a protocol concept / experimental infrastructure. Not live, regulated, guaranteed profitable, or investment-safe.

## Design Philosophy

The interface uses a geomorphic design system featuring:
- Dark mineral-like surfaces
- Layered terrain shapes
- Contour lines and topographic grid patterns
- Glowing fault lines and crystalline card edges
- Alphabet particles flowing like sediment or signal paths

Visual metaphor: Letters are raw minerals. Words are formations. Sentences are registered land parcels. The registry is the survey map. The oracle is the seismic pricing engine.

## Protocol Primitives

- **Letters**: Volatile priced primitives with demand, volatility, usage, and tax state
- **Words**: Composable value objects formed from priced character inputs
- **Sentences**: Unique registered assets with formula value, mint cost, and market value
- **Slots**: Prepaid minting capacity
- **Registry**: Ownership and transfer layer
- **Oracle**: Dynamic alphabet pricing engine

## Quick Start

### Local Development

Simply open `index.html` in a web browser:

```bash
cd /Users/jo/Downloads/language-fi
open index.html
```

Or use a local server:

```bash
# Using Python 3
python3 -m http.server 8000

# Using Node.js http-server
npx http-server -p 8000
```

Then visit `http://localhost:8000`

## Deployment

### Vercel

1. Push the code to GitHub
2. Import the project in Vercel
3. Deploy (static site, no build needed)

### Hugging Face Spaces

1. Push the code to GitHub
2. Create a new Space in Hugging Face
3. Connect your GitHub repository
4. Select "Static HTML" as SDK
5. Deploy

### GitHub Pages

1. Push the code to GitHub
2. Enable GitHub Pages in repository settings
3. Select main branch as source
4. Deploy (automatic via GitHub Actions)

## Sentence staking

A staked sentence uses the current oracle prices of its characters.

```text
Sentence Value =
Σ(character count × current oracle price)
```

Then staking score:

```text
Staking Score =
Sentence Value
× Character Performance
× Stillness Multiplier
× Diversity Multiplier
× Anti-Spam Score
```

Example:

```text

Weekly Character Performance: +9.4%
Stillness Multiplier: 1.25x
Diversity Multiplier: 1.08x
Anti-Spam Score: 0.97

Final Weekly Stake Score:
1.205 × 1.094 × 1.25 × 1.08 × 0.97
= 1.727 score units
```

Source weighting

Not every source should count equally, dude. Otherwise one spammy source can ruin the whole oracle.

Suggested weights:

Solana token names:          25%
Solana NFT collections:      20%
Solana domains:              15%
Language.fi registry:        25%
Gate.io token listings:      15%

Formula:

Weighted Letter Usage =
Solana Token Names × 0.25
+ Solana NFT Collections × 0.20
+ Solana Domains × 0.15
+ Language.fi Registry × 0.25
+ Gate.io Listings × 0.15

Oracle update cycle

Every few minutes:
1. Pull latest available data from approved APIs/indexers.
2. Take randomized samples from each source.
3. Normalize names to uppercase.
4. Count A-Z, 0-9, SPACE, and allowed symbols.
5. Compare current window to previous window.
6. Update letter prices and usage stats.
7. Publish oracle snapshot to the explorer.

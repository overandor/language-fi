# Economic Purpose and Utility

## Economic Purpose

Language.fi provides economic value by:

1. **Pricing Linguistic Assets**: Establishes a market price for linguistic primitives based on observable usage data
2. **Enabling Composition**: Allows users to compose word and sentence assets from priced primitives
3. **Oracle Verification**: Provides cryptographically verifiable pricing data for trust and transparency
4. **Anti-Manipulation**: Ensures pricing integrity through multi-source data and safeguards

## Utility

### API Access

**Current Utility**:
- `/api/primitives` - Get current primitive prices
- `/api/primitives/<symbol>` - Get specific primitive price
- `/api/oracle/ledger` - Access public oracle ledger
- `/api/oracle/runs/latest` - Get latest oracle run with attestation
- `/api/verification/stats` - Verify data across multiple sources

**Use Cases**:
- Developers building applications that need linguistic asset pricing
- Researchers studying language usage patterns
- Data analysts tracking linguistic trends
- Protocols integrating linguistic asset pricing

### For Users

1. **Access API** → Get primitive prices → Build applications

3. **Trade Assets** → Buy/sell word/sentence assets → Capitalize on linguistic trends

### For Creators

# Language.fi Neomorphic Dashboard

A neomorphic glassmorphism dashboard for the Language.fi linguistic asset protocol, displaying real-time oracle data from live cryptocurrency markets.

## Features

- **Real Oracle Data**: 100% real data from Dexscreener, Gate.io, CoinGecko, and Binance
- **Neomorphic UI**: Beautiful glassmorphism design with soft shadows and depth effects
- **Live Pricing**: Real-time letter prices based on market data
- **Advanced KPIs**: Compression Alpha, Entropy Resistance, Oracle Liquidity Shadow, and more
- **11 Letter Oracle Pages**: Detailed attribution for letters A, E, T, O, N, I, S, R, H, L, D, C

## Pages

1. **Landing Page** - Letter grid with real-time statistics
2. **Claim Page** - Asset claiming with cost calculator
3. **Dashboard** - Full letter prices table
4. **KPI Dashboard** - Advanced KPI tracking with news data
5. **Letter Oracles** - Individual pages for each letter with attribution

## Data Sources

- **Dexscreener**: 30+ trading pairs
- **Gate.io**: 2,230+ ticker symbols
- **NewsAPI Demo**: Real news headlines
- **CoinGecko**: 50+ cryptocurrency tokens
- **Binance**: Real-time ticker data

## API Endpoints

- `/api/primitives` - Get all letter/number primitives
- `/api/primitives/<symbol>` - Get specific primitive with attribution
- `/api/kpis` - Get advanced KPI metrics
- `/health` - Health check

## Verification

All data is verified as real from live cryptocurrency markets with no simulation or mock data.
